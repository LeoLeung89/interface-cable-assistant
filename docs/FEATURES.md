# 接口线缆助手

基于 WhatCable 公开 MIT 源码制作的本地独立版本。上游提交：58e588ab45350cf9512ce40d4080fbbef3b94ad0。新增代码独立实现，没有使用专有 Pro 插件，也没有修改许可验证或购买状态。

## 功能

- 实时系统功率、电压、电流，以及硬件支持的各端口 SMC 实测功率。
- 最近 10 分钟功率曲线，可选择系统或端口并导出 CSV。窗口显示时约每秒采样；开启历史记录后，窗口隐藏时约每 10 秒采样。退出应用后停止。
- 充电路径电阻估算：展示样本数、电流变化和拟合稳定状态。仅稳定时显示阻值，不给线材好坏评级。
- 充电、数据链路和显示诊断，复用公开诊断引擎。链路速率不是文件传输测速。
- 线缆自定义命名、改名、删除与重新指定。名称永久保存在本机，每次重插后手动指定，避免把同型号的另一根线自动当成原线。
- 端口状态、液体检测控制器状态和轻量针脚配置查看器；只展示系统实际提供的数据。
- 简版终端仪表盘和 JSON 输出。

## 使用

打开 `接口线缆助手.app`，自动出现「扩展诊断」窗口。也可点击菜单栏图标旁的波形按钮，或在菜单中选择「扩展诊断与线缆命名」。

在「连接诊断」页选择已连接端口，输入名称后保存。下次连接后使用「指定已保存线缆」。修改已指定名称会修改名称库记录；取消指定后可为当前连接保存一条新记录。

命令行工具位于应用内：

```sh
"/Applications/接口线缆助手.app/Contents/Helpers/whatcable" --lab-dashboard
"/Applications/接口线缆助手.app/Contents/Helpers/whatcable" --lab-monitor-json
"/Applications/接口线缆助手.app/Contents/Helpers/whatcable" --lab-snapshot
```

仪表盘每秒刷新，Ctrl+C 退出；输出到文件时仅输出一次纯文本快照。`--lab-monitor-json` 持续输出每秒功率 JSON，Ctrl+C 退出。可添加 `--no-usb-probe` 跳过深度 USB 探测。

## 数据含义和限制

- 系统功率是主板输入或电池放电读数，不等于插座耗电或电池充电功率。
- 端口读数明确区分「SMC 实测」「协商上限，非实测」和「控制器读数，可能滞留」。端口曲线只采用第一种，避免误画。
- 电阻估算针对整条充电路径，包含线缆、接头、充电器和 Mac 内部路径。台式 Mac 通常没有可用于估算的 USB-C 充电输入；本机实测即属于这种情况。功能保留，但没有满足条件的输入时不报告阻值。
- 显示诊断覆盖 macOS 暴露的 DisplayPort/USB-C/Thunderbolt 及相应原生视频链路。系统未提供的压缩状态、色彩格式或设备能力会显示未知，不能凭空补齐。
- e-marker 指纹通常只能识别型号，不是每根线的唯一序列号。软件不能发现所有未被系统观察到的快速换线。
- 针脚查看器显示系统的原始配置数值，不是逐针电压测量或导通检测，也没有声称掌握线材内部接线。

## 保存位置

- 名称库：`~/Library/Application Support/WhatCableLab/cables.json`。
- 独立偏好域：`local.leo.WhatCableLab`。
- 10 分钟详细曲线保存在内存；长期统计按小时汇总到本机历史文件。CSV 保存到你选择的位置。
- 不执行官方自动更新，避免覆盖自定义功能。桌面组件刷新由 macOS 调度。

## 构建

需要 Apple Silicon Mac、macOS 14+、Swift 工具链和已完成首次启动的完整 Xcode（构建组件）。本机 CLT 27 未附带 SwiftUI 新宏插件，主应用构建脚本优先使用本机已有的 26.5 SDK。

```sh
bash scripts/build-lab.sh /path/to/output
```

应用只做本地 ad-hoc 签名，没有冒用开发者签名或 Apple 公证。

## 1.5.0-lab.2 新增功能

### 线缆档案与命名候选

在「连接诊断」中为当前连接保存名称，然后在「线缆档案」里编辑照片、长度、购买链接、标称参数与备注。照片由你选择本地文件，缩小后保存到应用自己的目录，不上传。购买链接与备注是用户填写的信息，标称参数不会当成实测值。

重插时会列出相同 e-marker 型号指纹的候选，需要你点击确认；没有 e-marker 时手动从名称库指定。线缆唯一身份不能由型号指纹保证，因此不会默默自动绑定。

### 连接历史与端口定位

「连接诊断」可为端口填写实体位置，例如“背面左起第二个”。软件保留原始端口编号供核对，不猜机身左右顺序。

「历史与提醒」列出连接开始、结束、记录跨度、最佳链路速率、端口实测峰值和有效观测区间的估算电量。确认名称后，本次连接关联到该线缆档案。支持按档案筛选和导出 CSV。

软件退出或暂停观察会以“记录结束”收尾，不能当作已经确认的硬件断连；应用未运行期间的插拔也无法补记。

### 异常提醒与显示模式基线

默认只在应用内记录异常，系统通知需要你在「历史与提醒」中点击开启并授权。

- 60 秒内至少观察到 3 次连接，记录反复连接提醒。
- 同一连接的链路速率持续下降，连续 3 次观测确认后提醒。
- 显示模式连续 3 次稳定观测后记录；低于此前保存的正常基线时提醒，并记录前后模式变化。
- 同类提醒至少间隔 2 分钟，减少重复打扰。

显示基线按显示器信息和端口定位；移动到其他端口可能需要重新建立基线。无法区分的重复显示身份不自动建立基线或发出归属不明的提醒。主动降低分辨率、刷新率后，可在「显示诊断」中点击“记住当前显示模式”。提醒只是观察到变化，不等于已证明线缆故障。

### 连接拓扑

展示 Mac 下的活动 USB-C 端口、能确认归属的 USB 设备与集线器父子层级、显示设备，以及单独的 Thunderbolt / USB4 交换树。原生视频输出、内置或无法归属的设备单列，不编造无法确认的跨协议关系。

### 线缆对比与报告

在「线缆对比」中选择端口、填写快照名称并保存。换线后再保存一次，选择 A 和 B 并排比较链路速率、充电状态、显示模式与实测功率；可导出 Markdown 对比报告。尽量保持端口、设备和负载相同，软件不做自动因果判断，也不会写入外接硬盘进行测速。

窗口顶部“诊断报告”可导出当前各端口的状态、功率来源、诊断依据与近期异常。报告不直接包含设备序列号或原始 EDID，文件由你决定保存位置。

### 长期功率统计与保存策略

「长期统计」按小时展示平均功率、峰值、估算电量和有效覆盖时长，支持系统输入、电池放电与各端口 SMC 实测数据筛选，以及 CSV 导出。

电量使用相邻有效读数的梯形积分，间隔超过 35 秒、读数缺失、睡眠、换线或电源来源切换时不跨段补算。它是有效观测时段的估算，不能用来推算整天未观测的用电，也不是插座侧电表读数。

历史默认保留 90 天，可改为 7、30、90 或 365 天，也可暂停记录。缩短保留时间会清理超期历史，不删除线缆档案。汇总约每 30 秒落盘，正常退出时保存；强制结束可能丢失最近一小段记录。

新增本地文件：

- 历史与设置：`~/Library/Application Support/WhatCableLab/archive-v1.json`
- 照片副本：`~/Library/Application Support/WhatCableLab/photos/`

旧版 `cables.json` 会兼容读取，保留原有名称和 ID。读到损坏或不支持版本的历史文件时停止写入并显示错误，不用空文件覆盖原记录。

### 本地验证

运行 `bash scripts/test-lab.sh`。本版 315 项针对性测试通过，包括组件数据验证、档案落盘重读、旧格式兼容、异常确认与限频、休眠/断开后的功率积分边界、原有电阻和诊断算法。

## 1.5.0-plus.1：更名与桌面组件

应用更名为 **接口线缆助手**。继续使用原有内部标识与数据目录，线缆档案、历史、照片与偏好无需迁移。

新增「Plus 端口与线缆」「Plus 功率概览」，支持小、中、大尺寸。右键桌面 → 编辑小组件 → 搜索 接口线缆助手 后添加。主窗口「桌面组件…」按钮可查看同步状态。

组件显示端口位置、已确认的线缆名称、协议、可用的 SMC 实测功率，以及系统功率与最近曲线。组件库示例明确标注“示例”。请保持应用运行、历史记录启用，才能持续生成快照。底部标记读数时间，超过 15 分钟的功率不再显示为当前值。刷新由系统调度，每秒波动请在主窗口查看。

组件独立实现且保留系统沙盒，不使用原作者 App Group，不修改购买状态。主程序仅在系统初始化组件自身的容器后同步快照。

1.5.0-plus.2 修复：组件更名后系统仍缓存旧目录的启动进程，导致版本不匹配和灰色占位。更新本应用登记并重载一次组件服务后，已从 Plus 路径启动。连接组件改用原版公开 PortSummary 字段，显示连接类型、链路速率、设备数量、显示器名称与模式、充电器额定功率，保留自定义名称；用户已删除旧实例并重新添加，确认桌面显示正常。充电器功率标签为额定/协商信息，不是实测功率。

另修复系统设置入口为空页面的问题，已实际打开设置并确认选项正常显示。

1.5.0-plus.3：按用户反馈放大组件标题、连接名称、详情与速率标签。中尺寸保留两行连接，小尺寸聚焦一个端口，大尺寸展示更多连接。

1.5.0-plus.4：进一步明确放大组件字号：连接名称 16pt、详情 13pt、速率标签 14pt、顶部标题 15pt、底部时间 12pt。

## 1.5.0-plus.5：连接名称与线缆说明

主界面连接标题旁的铅笔，或「连接诊断」→「编辑连接显示名称与线缆规格…」，可编辑「显示名称」「线缆类型」「最大规格」。例如显示名称填“左侧显示器”，线缆类型填“USB-C 转 DP”，最大规格填“最高 DP 1.4”；或类型填“USB-C”，规格填“最高 40 Gbps”。线缆档案也可修改这些字段，档案名称与显示名称分开保留。

组件标题优先显示自定义连接名称，下一行显示类型和最大规格（标为“手动”）。大尺寸保留显示器型号和当前模式，最多展示四个连接；小、中尺寸优先显示线缆说明。右侧速率仍是当前连接的速率，不会被填写的上限替换。未填写类型时不推测是 USB-C 直连还是转 DP，也不根据当前速率推断线缆上限。

速率单位是 Gbps（每秒十亿比特），不是 GB。DP 线缆可填写经产品规格确认的 DP 等级；没有证据时留空。软件没有验证手动填写的规格。

信息保存在线缆档案中。重新插入后，先在连接诊断里手动指定或确认原档案，才恢复对应名称和规格，以免错误套用到换上的另一根线。编辑时连接变化会阻止保存。旧档案兼容读取。

## 1.5.0-plus.6：自动预填建议

打开连接命名时，空白字段默认使用识别建议：设备名称优先取显示器名称，其次附件名称；有显示与 USB 功能时建议 USB-C，仅有显示时建议 USB-C 转 DP，推测接法均注明“建议”，不能据此确认物理插头。已保存的非空值优先保留，可点击「重新填入识别建议」覆盖当前编辑内容。

最大规格仅在读到线缆 e-marker 的速度声明时预填，并标记 e-marker 来源；没有声明则留空并显示未知提示。原始速度编码 3 在 PD 版本间有歧义，显示 20/40 Gbps 等级，不将它冒充唯一确定上限。当前链路速度不参与最大规格建议，USB 等级也不作为 DP 视频带宽上限。保存仍由用户确认。

## 1.5.0-plus.7：原生 HDMI 命名

Mac 原生 HDMI 卡片及「显示诊断」里的 HDMI 显示器标题旁新增铅笔。默认填入显示器名称与接口类型（例如 28C1Q、HDMI）；最大规格未知时留空，可以按线材产品规格填写。保存后同步到组件，组件现包括原生 HDMI 输出，大尺寸最多显示五条连接；超过四条时优先显示线缆说明以保持字号。

HDMI 的说明按物理接口保存在 `~/Library/Application Support/WhatCableLab/native-display-labels-v1.json`，不代表自动识别了线缆。换显示器或换 HDMI 线后应重新核对，不能将当前画面模式作为线材上限。损坏或不支持版本的文件会暂停写入，避免覆盖原数据。
